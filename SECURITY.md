# Security Policy

## Reporting a vulnerability

Please do not open a public issue for a credential leak or a vulnerability. Email `hpnetwork@hpnetwork.top` with a short reproduction, affected version, and a safe contact address. Remove real secrets from any report before sending it.

I will acknowledge reports within seven days and coordinate a fix or mitigation before public disclosure when practical.

## Scope

This project is a local repository scanner. Its checks are heuristics and are not a replacement for a dedicated secret scanner, dependency audit, or code review.
